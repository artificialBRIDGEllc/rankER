# rankER brand

Editorial ranking mark: two rising bars + a **typeset** capital R. The R is Figtree 600 — never a custom-drawn letter.

## Mark

- Primary: navy tile `#070B12`, steel bars `#8B9BB4` / `#C5D0DC`, ice R `#E8EEF7`
- Inverse (site chrome): ice tile, navy bars + navy R
- Clear space: 1× bar width. Minimum 24px.

## Type

- Display: Newsreader
- UI / wordmark: Figtree 400–600
- Mark letter: Figtree 600 “R”

## Color

| Token | Hex | Use |
|---|---|---|
| Navy | `#070B12` | tile, inverse ink |
| Ice | `#E8EEF7` | type, inverse tile |
| Steel | `#C5D0DC` / `#8B9BB4` | rank bars |
| OK / warn / crit | `#7DBA9A` / `#C4A574` / `#C48A86` | score states |

Do not recolor the R independently of the bars. Do not replace the R with a geometric path.
